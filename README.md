# Projects

A collection of my programming projects, experiments, and exercises.

This repository contains projects written in different programming
languages. Some projects are implemented multiple times in different
languages as a way to compare their syntax, features, and approaches.

## Repository Structure

Each project is maintained in its own Git branch.

The `main` branch contains the repository documentation and
shared configuration, while individual project branches contain
their respective source code.

## Why?

Mostly to learn.

I use these projects to practice programming concepts, experiment
with different languages, and understand how the same problem can
be approached differently depending on the language.

Some projects may be simple. Some may be unnecessarily complicated.
That's part of the fun.
